# Accessibility

The aim is for every part of Project Lodestone to be usable by people who rely on
assistive technology.

## What is in place

- **Pitch book:** slides use real text boxes (not images of text), a reading order that
  follows the visual layout, and chart colours chosen for contrast. Every figure is also
  stated in text or a table.
- **Excel model:** each tab opens with a title and a short description; inputs, formulas
  and links use a colour legend *and* are listed by name on the Cover tab, so colour is
  never the only cue.
- **Dashboard:** built on Streamlit's standard widgets, which are keyboard-operable and
  labelled. Every chart has a data table beside or beneath it.
- **Portfolio site:** semantic HTML, descriptive link text, alt text on screenshots,
  and support for light and dark colour schemes.

## Feedback

If something is hard to use, please open an issue describing the barrier and the
assistive technology you use.
